# NABD Agentic AI: Demo execution and two-year backtest

This runbook applies ONLY to experimental/nabd-agentic-ai-test and nabd-agentic-ai-test Render. Never deploy to main or connect a real trading account.

## Proven versus not proven
The independent MT5 Demo preflight trade was broker-confirmed. AI currently analyzes both markets and risk gates reject unsafe/weak WATCH decisions. A **broker-confirmed trade generated by AI through the Demo Executor is NOT yet verified**.

CI now covers HMAC, stale sensor rejection, wrong Demo account, mismatched symbol, replay/idempotency and simulated AI -> saved decision -> signed intent -> simulated executor pickup -> signed ACK. An EA-reported fill with broker ticket is NOT independent broker confirmation.

## Real Demo execution acceptance checklist
1. Both observer and executor must run on the SAME isolated JustMarkets Demo account, NEVER Real.
2. The sensor status endpoint must show new authenticated observations and market freshness.
3. The demo-trade status endpoint must show enabled=true and executorOnline=true and sensorFreshness for the intended market must be quoteFresh=true.
4. AI must produce an authenticated, persisted BUY_WATCH or SELL_WATCH decision with confidence >=0.82 and deterministic indicator, spread, time and exposure guards must pass.
5. created, delivered and brokerAcks must increase in order. Match deal ticket in MT5 History (symbol, account, volume, timestamps), not merely ACK.
6. Do not weaken the confidence threshold, broker freshness, demo isolation or risk caps to force a trade.

## Extract genuine two-year JustMarkets Demo candles

Windows prerequisites: JustMarkets Demo open in MT5, Python and MetaTrader5 Python package, Node.js 24+.

First install package with: python -m pip install MetaTrader5

Run the export utility with these arguments on ONE command line, replacing placeholders with verified historical cost ASSUMPTIONS:

python agentic-experimental/export-mt5-history-2y.py --gold-spread-points GOLD_POINTS --btc-spread-points BTC_POINTS --slippage-points SLIPPAGE_POINTS --commission-per-lot ROUND_TRIP_USD_PER_1_LOT --output nabd_agentic_2y_input.json

The program exports M5/M15/H1/H4 closed candles. It fails closed if MT5 is not Demo. It excludes credentials/account IDs. If historical coverage is shorter than 730 days, increase MT5 max bars and fetch more history from JustMarkets before proceeding.

**Historical spread, slippage and commission cannot be reconstructed from OHLC alone.** Supply verified explicit assumptions, not fabricated fills.

## Archived AI decisions are essential
The current research journal records decisions and analyzed-at timestamps, but does NOT retain historical Bid/Ask snapshots for every decision. Neither JustMarkets M5 candles nor the existing dashboard backtest can retroactively reproduce AI's genuine decisions from before AI was running. Without authentic point-in-time decision archives, the replay deliberately shows NOT_TESTABLE_NO_ARCHIVED_AI_DECISIONS, with no invented win rate or PnL.

For real point-in-time replay, provide locally a JSON array of archived decisions. Each entry needs:
symbol, closedBarTime, analyzedAt, stance, confidence, bid, ask, quoteAt.
Each quote and decision timestamp must correspond to an actually recorded historical observation and never refer to future information.

Use --decisions archived_decisions.json with the exporter to incorporate them, then run:

node agentic-experimental/agentic-replay-backtest.mjs nabd_agentic_2y_input.json nabd_agentic_2y_report.json

The engine calls the SAME Demo intent gate as the running experimental service. It enforces min 730 days and rejects future quotes, duplicate decisions, invalid histories, wrong broker identity, weak WATCH plans and bad risk/indicator checks.

## Replay assumptions and interpretation
Offline only. No network calls or real broker orders. Uses next available M5 open after recorded AI output as a simulated fill, user-supplied fixed cost assumptions, stop-first if SL/TP touched within same OHLC bar, no swap, and no historical news-event execution evidence. It reports trades, net R, profit factor, win rate, simulated USD PnL and max drawdown, but **must never be presented as broker-confirmed profit or complete live-news backtest**.

The 2-year genuine performance study is BLOCKED until actual broker history, archived point-in-time decisions plus quotations and cost evidence are available. Backtesting old dashboard strategy is a separate comparison, not proof that the Agentic AI performs as claimed.
